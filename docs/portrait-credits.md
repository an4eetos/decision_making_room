# Portrait credits

Every portrait comes from Wikimedia Commons, downloaded at 400 pixels wide and
shown with a greyscale and colour-overlay treatment so the set reads
consistently. That treatment is an adaptation; the originals are linked below.

Files marked CC BY-SA are licensed under the Creative Commons
Attribution-ShareAlike licence named, and the adapted versions shown in the
interface are shared under the same licence. Public-domain files carry no
restriction, but are credited anyway.

Boyd has no freely licensed portrait and is shown as a monogram.
